# 💰 Controle de Despesas

Sistema web de gerenciamento de gastos pessoais desenvolvido como atividade prática da disciplina de Front-End.

## 📋 Descrição

Aplicação que permite cadastrar, visualizar, filtrar e excluir despesas pessoais, organizadas por categoria. Os dados são manipulados dinamicamente via JavaScript, sem recarregar a página.

## 🚀 Como rodar o projeto

1. Clone ou baixe este repositório
2. Abra a pasta do projeto no VS Code
3. Clique com o botão direito no `index.html`
4. Selecione **Open with Live Server**
5. A aplicação abrirá automaticamente no navegador

> Não é necessário instalar nada. Basta um navegador moderno.

## ✅ Funcionalidades

- Cadastrar despesas com descrição, valor e categoria
- Validação do formulário (descrição vazia e valor inválido)
- Excluir despesas individualmente
- Calcular o total automaticamente
- Contador de despesas cadastradas
